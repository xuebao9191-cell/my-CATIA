# CATIA 笔记 01 · 界面与基础操作

## 启动与工作台
- 启动后出现**工作台选择**，常用工作台：
  | 工作台 | 用途 |
  |---|---|
  | Part Design | 实体零件建模 |
  | Sketcher | 二维草图 |
  | Generative Shape Design (GSD) | 曲面设计 |
  | Assembly Design | 装配 |
  | Drafting | 工程制图 |
- 切换工作台：菜单 `Start` 或右上角工作台图标。

## 鼠标操作
| 操作 | 效果 |
|---|---|
| 中键拖拽 | 平移 |
| 中键+右键 / 中键按一下再拖 | 旋转 |
| 右键+中键 / Ctrl+中键 | 缩放 |
| 中键双击+拖 | 缩放 |

## 结构树 (Specification Tree)
- 左侧结构树记录建模全过程，**先看树再动手**。
- 命名规范：每个特征重命名（双击特征名），利于后期修改。

## 常用快捷键
- `Ctrl+U`：更新
- `Ctrl+Z`：撤销
- `F3`：显示/隐藏结构树
- `Alt+Enter`：属性

## 文件格式
- `.CATPart` 零件、`.CATProduct` 装配、`.CATDrawing` 图纸。
- 交换格式：STEP (.stp)、IGES (.igs)。

> 技巧：建模前先定好**基准面**（XY/YZ/ZX），所有特征尽量从基准出发。
