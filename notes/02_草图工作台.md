# CATIA 笔记 02 · 草图工作台 (Sketcher)

## 进入方式
- 新建 Part → 选择一个平面/基准面 → 点击**草图图标**进入。

## 核心命令
| 命令 | 快捷键 | 说明 |
|---|---|---|
| 轮廓 | 默认 | 连续直线+圆弧 |
| 矩形 | | 含三种矩形 |
| 圆 / 圆弧 | | 多种方式 |
| 样条线 | | 自由曲线（翼型可用） |
| 镜像 | | 对称复制 |
| 偏移 | | 等距偏移轮廓 |

## 约束 (Constraint)
- **几何约束**：相合、平行、垂直、相切、同心、固定。
- **尺寸约束**：长度、角度、半径，驱动参数。
- **显示状态**：绿色=完全约束；白色=欠约束（可拖动）。
- 常用：`D` 快速标注；`Ctrl+U` 更新。

## 关键技巧
1. **封闭轮廓**：拉伸/旋转前轮廓必须闭合。
2. 先加**几何约束**，再加**尺寸约束**。
3. 翼型建模常用：样条线描点 → 约束 → 拉伸。

## 常见报错
- "轮廓未闭合" → 检查端点是否相合，用快速修剪清理多余线。

> 草图是参数化建模的**根**，草图约束越规范，后期改尺寸越省事。
