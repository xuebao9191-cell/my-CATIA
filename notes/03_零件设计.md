# CATIA 笔记 03 · 零件设计 (Part Design)

## 基础特征
| 特征 | 用途 |
|---|---|
| Pad（凸台） | 草图沿方向拉伸成体 |
| Pocket（凹槽） | 反向挖除材料 |
| Shaft（旋转体） | 草图绕轴旋转 |
| Hole（孔） | 打孔（含螺纹孔） |
| Rib（加强肋） | 沿引导线扫掠 |
| Fillet（圆角） | 倒圆角 |
| Chamfer（倒角） | 倒直角 |

## 操作流程（示例：方块带孔）
1. 选 XY 面 → 草图 → 画矩形 → 约束 → 退出草图。
2. `Pad` 指定高度 → 生成实体。
3. 选上表面 → 草图 → 画圆 → `Pocket` 贯通 → 打孔。

## 高级特征
- **Thickness（抽壳）**：实体内部掏空成薄壁（机身蒙皮思路）。
- **Boolean（布尔）**：两个体做加减交集。
- **Mirror（镜像）** / **Rectangular/Circular Pattern（阵列）**：对称与阵列结构。

## 参数化修改
- 双击尺寸 → 修改数值 → 树更新，模型随之变化（**这就是参数化**）。
- 用**公式**把关键尺寸关联。

## 飞行器常用
- 蒙皮：Thickness 抽壳 + 曲面。
- 翼梁/翼肋：草图轮廓 + Pad/Pocket + 阵列。
- 铆钉孔：草图打孔 + 圆形阵列。

> 建模思路：**先草图 → 再特征 → 后细节（孔/圆角/倒角）**。
