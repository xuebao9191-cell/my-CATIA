# CATIA 笔记 04 · 曲面设计 (GSD) 与装配/制图

## 一、创成式曲面设计 GSD

### 常用曲面命令
| 命令 | 用途 |
|---|---|
| Loft（多截面） | 多个截面放样成曲面（机身/机翼常用） |
| Sweep（扫掠） | 沿引导线扫出曲面 |
| Fill（填充） | 用轮廓补面 |
| Offset（偏移） | 曲面等距偏置（蒙皮厚度） |
| Trim / Split | 修剪 / 分割曲面 |
| Join（结合） | 多张曲面缝合成一张 |
| Sewing（缝合） | 曲面缝合到实体 |

### 曲面→实体
- **Close Surface / Thick Surface**：封闭曲面成实体、曲面加厚。

### 飞行器应用
- 机身：多截面 Loft + 蒙皮 Offset。
- 机翼：翼根/翼尖截面放样 + 前后缘封边。

## 二、装配设计 (Assembly Design)

### 核心命令
| 命令 | 作用 |
|---|---|
| Coincidence（相合） | 面/轴线对齐 |
| Contact（接触） | 面贴面 |
| Offset（偏移） | 指定距离约束 |
| Fix（固定） | 锁定一个组件定位基准 |
- 装配思路：**先固定基准件，再逐个约束**。
- 更新：`Ctrl+U` 刷新装配约束。

### 装配检查
- `Analyze → Degrees of Freedom`：检查自由度。
- `Interference`：干涉检查。

## 三、工程制图 (Drafting)

### 生成视图
1. 新建 Drawing → 选模板（A4/A3）。
2. 插入**主视图** → 自动生成投影视图。
3. 辅助视图：局部放大、剖视图、轴测图。

### 标注
- 尺寸标注 `D`：线性/直径/半径/角度。
- 形位公差、表面粗糙度、基准符号，符合 GB 标准。

### 导出
- 打印 / 导出 PDF 交付。

---

> **总流程**：草图 → 零件设计 → 曲面设计 → 装配 → 制图 → 干涉检查。
